# EXPTRACK 1.8.0 - Android updater

VersionCode 15. Adds Config > App Updates: installed version, manual repository check, available-version status, download/progress/cancel/retry, and Android installer handoff. Native code verifies checksum, package, versionCode and matching signer. GitHub raw release descriptor is generated by the build, with fallback for older repo layouts. Unauthenticated GitHub API rate limits were encountered during development; the shipped implementation avoids that API and uses the public download host.

TypeScript, targeted ESLint, browser platform fallback, signed release/debug builds and APK signature/alignment verification passed. Live GitHub metadata and real download were tested in an older debug baseline; the production APK was rejected because it is a different package from debug. AppUpdateTest instrumentation passed rejection cases for hash/version/package/signature/revision tampering. Config opened Android's installation-source permission screen and Update confirmation for a trusted debug candidate. The actual update completed from versionCode 13 to 15; a SQLite spending record remained unchanged. Same-version installation was rejected afterward. Test fixtures and fake authentication were limited to the debug emulator. The release demo account is preserved and updated separately. APK checksum is recorded beside the artifact.
