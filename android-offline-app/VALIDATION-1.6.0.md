# EXPTRACK 1.6.0 - Custom spending reminders and compact navigation

Android versionCode 12. Config supports 1-6 spending reminders daily, each with a chosen local time. The existing 20:30 default and legacy disabled preference are retained. Settings are account-specific on this device, survive restart, and are not cloud preferences. Replacing schedules cancels all six reserved alarm IDs before scheduling the selected times. Turning reminders off, signing out, blocked permissions and switching accounts clear old alarms. Tapping any reminder opens Home. Notification icons and inexact scheduling remain unchanged.

Includes the local UI refinements: equally aligned bottom navigation, compact month selection above available balance, sync details only in Config, removed balance helper text, and removal of the duplicate Config icon from the mobile header. Desktop retains a text Config link where bottom navigation is absent.

Validation: TypeScript and targeted ESLint passed. scripts/check-reminder-settings.mjs verifies migration/default, custom times, 1-6 slots, duplicate/invalid rejection, midnight, stale alarm cancellation, off/on and logout, account settings, permission denial, scheduling failure recovery and notification appearance. Signed release/debug builds and APK signature/alignment checks passed. Emulator UI and native pending-alarm checks passed with scripts/check-native-reminder-settings.mjs (1/3/6 alarms, chosen times, persistence, duplicate rejection, stale alarm removal, off/on and logout cancellation); it uses an isolated test account and intercepted auth/sync, without writing production account data. Reminder delivery time can be delayed by Android battery restrictions.
