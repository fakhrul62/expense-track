# EXPTRACK 1.10.0 - Reports, fonts and money corrections

Android versionCode 17. Bank Balance is a reserved income source for opening available funds. Existing app balances are not automatically copied into it; enter it only when recording previously untracked funds. All devices and server need this version to classify the new stable income ID consistently.

Config offers bundled Inter, Arial-style Arimo, Calibri-style Carlito, system and Retro font choices. The default is now readable Inter; selection is saved on this device and applies across forms, navigation and monetary totals. Arimo/Carlito OFL licenses are included in public/licenses/fonts.txt. Proprietary Arial/Calibri font files are not distributed.

Reports are on /reports, reachable from a small chart icon in the header and a Config link. Monthly income/expenses/net cash flow, starting/ending cash, daily bar chart with daily figures table, and category breakdown use the existing ledger and integer-cent sums. Opening bank balances and actual loan cash movements are included, future-dated entries and tracking-only debts are excluded. This is a cash report, not a profit report. Native route interception includes /reports.

Owed to Me now clearly offers Record installment / payment. Each payment reduces the remaining loan total and adds actual cash received, with history retained. Confirmed deletion of a mistaken borrowing or lending removes its principal and all known linked payments in one local transaction, recalculates cash, and queues expense tombstones. Native SQLite deletion derives linked records in its own transaction and checks account identity. Browser IndexedDB deletion performs the same operation atomically. Unrelated entries and categories are preserved.

Checks: scripts/check-money-tools.mjs exercises Bank Balance, monthly reports/chart/opening/closing, font changes and reload, two installments, cancelled deletion, deleting paid borrowed/lent loans, cash/report recalculation and synced tombstones with isolated test accounts and simulated sync. scripts/check-report-math.mjs validates cent arithmetic, prior-month balances, future/existing debt exclusions, daily grouping and empty months. Targeted lint and TypeScript/build checks run during delivery. Native --native variant runs financial/form tests through SQLite. Concurrent unseen payments recorded on another device after deletion remain subject to the existing offline synchronization semantics; deletion confirmation covers payments currently linked on this device.

Delivery evidence: browser and native SQLite money-tools journeys passed in full; report-math checks passed. Native account-mismatch deletion was rejected. The signed release build, v2/v3 signature/alignment checks, TypeScript and targeted lint passed. SHA-256 and android-update.json match the delivered 1.10.0 APK. Preview fonts and report layouts were visually inspected in browser, with native screenshots inspected during final review.
