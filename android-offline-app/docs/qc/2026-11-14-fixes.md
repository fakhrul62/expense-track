# EXPTRACK v1.11.1 QC fixes

Patch release, Android code 19. These fixes are included in v1.11.3. The QC below was performed locally before publication.

## Changes

| Finding | Resolution |
| --- | --- |
| QC-01: expense becomes income | Shared case-insensitive reserved-name validation in client/server; mappings across income/expense classification are prohibited. Unsafe legacy aliases are removed without changing the direction of the uploaded entry. A read-only check of the connected cloud database found zero unsafe aliases. No speculative financial migration was performed. |
| QC-02: orphaned repayment | Server reconciliation runs after the entire sync batch, including empty pulls. If its loan is missing/deleted or has an incompatible direction, a payment becomes an ordinary income/expense entry. Amount, date and bank/cash source remain intact. Home can edit/delete it. A sync notice explains recovery; the original record is retained privately for provenance. Valid same-batch payments stay attached. |
| QC-03: advisories | Mongoose 9.12.1, glob 14.0.6, minimatch 11.0.8 for affected modern branches, uuid 11.1.1. Live GitHub catalog queries returned zero active matches for these four patched coordinates. Unaffected minimatch 3.x stays unchanged. xcode UUID CommonJS smoke check, ESLint, Capacitor sync and builds verify compatibility of transitive overrides. |
| QC-04: modal focus | Safe Cancel focus, containment of outside focus, Tab/Shift+Tab trapping, inert background and focus restoration. Android touch triggers are remembered because touch can blur buttons before the dialog opens. Stable transaction focus keys support refreshed rows; empty/busy dialogs remain focusable. |
| QC-05: contrast | Stronger small report labels and darker Retro orange action backgrounds. Sampled reports/controls across Studio, Paper, Garden, Ink and Retro returned zero contrast failures in the regression probe. This is not a full WCAG certification. |
| QC-06: note length | Form validation uses the actual serialized source/note budget, displays remaining capacity and flags excessive notes before save. Save is disabled for excess capacity; quotes/escaped characters are covered. |
| QC-07: CSV safety | Text formulas with leading whitespace/control characters are neutralized. Actual numeric cells remain numeric, including negative net cash flow. |
| QC-08: loan performance | Payments are grouped once by loan ID and direction. The same desktop 1,000-loan/2,000-record fixture fell from 1,785 ms to approximately 10 ms. Date ordering, future payments, partial totals and lending/borrowing separation are regression tested. |
